# Garmin Workout Builder 🏃‍♂️🚴‍♂️🏊‍♂️

[![Live Demo](https://img.shields.io/badge/status-live%20demo-brightgreen)](https://emanuelfs4.github.io/garmin-workout-builder/)

**Garmin Workout Builder** is a sleek, modern web application designed to create, customize, and export structured workouts directly into the Garmin-compatible JSON format. 

Whether you are configuring running intervals, cycling power thresholds, or swimming pool sessions, Garmin Workout Builder lets you map out your training blocks and download or copy them instantly.

Access and use the tool directly in your browser without downloading anything:

## Features

* **Multi-Sport Support:** Dedicated configuration profiles and target metrics for **Running**, **Cycling**, and **Swimming**.
* **Flexible Durations:** Set intervals and steps in seconds, minutes, meters, or lap button triggers.
* **Advanced Pacing & Targets:** Input pace ranges in standard `min:sec` format (e.g., `4:15` to `4:30`), heart rate zones, power (watts), cadence, or speed.
* **Repeat Loops & Sub-steps:** Easily structure complex multi-step interval workouts with custom iteration loops.
* **Step Reordering & Customization:** Rearrange your workout blocks dynamically using up and down controls.
* **Instant Export:** Generate, copy, or download the official Garmin JSON payload with a single click.

## Usage & Importing to Garmin

1. Open the live app link above.
2. Choose your sport tab at the top.
3. Enter your workout name and description.
4. Add, reorder, or customize your warmup, intervals, recovery loops, and cooldowns.
5. Click **Generate Garmin JSON** and download your `.json` file.
6. To import the generated JSON files into Garmin Connect, you will need the [Garmin Workout Importer Google Chrome Extension](https://chromewebstore.google.com/detail/faebbfokokipdpkbolpbpfadmgdbanpo?utm_source=item-share-cb).
